## 2. Priorities

### P0 — before anyone else installs it
1. **Sokoul account client**: sign-in by TV code/QR, profiles and progress sync against `/api/tv/link` and `/api/sync`.
2. **Own website for the TV link**: `PUBLIC_SITE_URL` defaulted to a third-party site (`API/Mainapi/routes/tvLink.js:62`), so today the QR points to a third-party site.
3. **Release signing**: `tv/build.gradle.kts` signs release with the debug key, `versionCode = 1`. Create a release keystore (kept outside the repo) and bump versionCode per build.
4. **Backend before any public exposure**: 41 npm vulnerabilities (5 critical: `@fastify/express`, `@fastify/middie`, `bitcoinjs-lib`, `proxy-addr`, `tar`); CORS allows ~24 upstream-project domains with credentials (`middleware/cors.js:9-33`); ports bound on 0.0.0.0 (`API/docker-compose.yml`); owner's Real-Debrid/Xtream/BestDebrid keys served to every user; `cloudflareproxy/worker.js` is an open proxy (never deploy).

- Finish settings redesign and premium-unified-design; tablet portrait / phone layouts for anime, collections, manga, onboarding.

- Tests for the `tv` module (player, form-factor choice, CurlImpersonate) and the Coflix/FStream/VoirDrama scrapers.

### P2

## 5. Website, zero cost

- **Static site on Cloudflare Pages** (free: 100k requests/day [web]): TV-code page `/tv?code=`, BIP39 / Google / Discord
  sign-in, sessions, profile manager, download page (APK, PC), privacy, terms, third-party (CC BY-NC) and TMDB attribution.
  A upstream React/Vite site with these pages exists outside the repo (`Desktop/Sokoul-reference/Sokoul a adapter`): it
  can be reduced to these pages and re-branded.
- **API behind it**: the existing Node + MySQL + Redis cannot run on Workers/D1 without a full rewrite. Free options:
  Oracle Always Free A1 (2 OCPU / 12 GB since 2026 [web], card required) running `mainapi + mysql + redis` only, through
  Cloudflare Tunnel; fallback: Tunnel from the owner's PC (PC must stay on).
- Public instance: account, profiles, sync and TV link only. No scraper, live TV, debrid or proxy routes, no
  proxiesembed: those relay copyrighted streams and would get the Oracle/Cloudflare accounts closed. Cloudflare's terms
  also restrict video on free plans.

## 6. Legal constraints (facts, not legal advice)

- Code derived from the upstream project is CC BY-NC 4.0: attribution required, no commercial use (the VIP payment routes conflict).
- The app and server scrape unlicensed streaming sites (Coflix, French-Stream, Wiflix, Darkiworld, Anime-Sama…) and use
  TLS-fingerprint impersonation. Fine for private use on one's own devices; publishing it (store, public server) is
  where the risk lies.
- Real-Debrid and Xtream accounts are personal: sharing them breaks their terms.
